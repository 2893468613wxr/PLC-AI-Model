# 2026-10-06

## UI 修复：DataGrid 选中行黑字 + 数据记录预览滚动

**问题 1：选中行文字变黑不可读**
- 根因：未覆盖系统默认 DataGridRow 选中样式（浅色高亮+黑字）；且 `RowBackground`/`AlternatingRowBackground` 以本地值写入行 Background，会压制行样式触发器。
- 修复（App.xaml）：
  - DataGrid 样式移除 RowBackground/AlternatingRowBackground，改用 `AlternationCount=2`
  - 新增全局 `DataGridRow` 样式：交替行(#26262F)、悬停(#2C2C42)、选中(#2F4266 + 白字)，触发器按"交替→悬停→选中"顺序声明（后者优先）
  - 新增全局 `ListBoxItem` 样式（数据记录页文件列表同样有浅色选中问题），含圆角+悬停/选中深色态

**问题 2：数据文件预览无法滚动**
- 根因：DataLogView 主 Grid 三行为 Auto/Auto/*，内容区(文件列表+预览)在 Auto 行里被数据撑高超出窗口，DataGrid 内部滚动条永远不生效。
- 修复：改为 Auto/*/Auto，内容区占满剩余高度，DataGrid 与文件 ListBox 各自获得有界高度 → 内部滚动条正常工作。

验证：编译 0 错误；启动运行 10s 无样式运行时异常。

### 经验
- WPF DataGrid 自定义深色主题时，RowBackground/AlternatingRowBackground 与行样式触发器冲突是经典坑，必须改用 AlternationIndex 触发器实现交替行。
- 容器 Grid 行用 Auto 包裹 DataGrid/ListBox 会让内部滚动失效，长内容区域必须用 * 。
